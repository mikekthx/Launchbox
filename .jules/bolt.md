## 2024-05-24 - O(N log N) LINQ Sort Bottleneck on Filter Text
**Learning:** C#'s LINQ `OrderByDescending` with a boolean predicate (`.OrderByDescending(a => a.Name.StartsWith(...))`) imposes an internal O(N log N) sorting overhead and creates extra delegate allocations that are especially punishing in real-time UI filtering algorithms running on every keystroke.
**Action:** When filtering and partitioning a small collection into exactly two buckets (e.g. prefix matches vs substring matches), always replace the LINQ query with a manual single-pass `foreach` loop that segregates the items into two `List<T>` objects and concatenates them. This achieves O(N) performance and keeps the main UI thread much faster.
