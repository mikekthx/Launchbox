## 2025-02-28 - Link Setting Inputs to Visual Headers
**Learning:** In WinUI 3 XAML settings or forms, to properly support screen readers, explicitly link interactive controls (e.g., `ComboBox`, `TextBox`) to their visual headers. Assign an `x:Name` to the descriptive `TextBlock` and set `AutomationProperties.LabeledBy="{Binding ElementName=HeaderName}"` on the interactive control.
**Action:** Always assign an `x:Name` to descriptive header text blocks in settings pages and use `AutomationProperties.LabeledBy` on adjacent interactive controls (especially text inputs and combo boxes) to ensure screen readers provide correct context.
