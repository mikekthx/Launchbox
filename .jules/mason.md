## 2024-05-20 - ListViewBase Keyboard Navigation and ItemClick
**Learning:** In WinUI 3, `ListViewBase` controls (like `GridView`) do not natively fire the `ItemClick` event on an `Enter` key press, even when `IsItemClickEnabled` is true. Furthermore, standard extensions that rely on casting the focused item strictly to `GridViewItem` break if applied generically to a `ListView`.
**Action:** When implementing MVVM-friendly keyboard navigation without code-behind, create an attached behavior for the `KeyDown` event that explicitly checks for `VirtualKey.Enter`. Resolve the focused item via `FocusManager.GetFocusedElement(xamlRoot) as FrameworkElement` (rather than a specific container type like `GridViewItem`) and execute the bound `ICommand` using the focused element's `DataContext`.
